# stay
Bed and Breakfast 

## Kjøre prosjektet
1. Klon CrudOps-forken: https://github.com/SanderBendal/crudops
2. Lag en `.env`fil i crudops-mappen med:
   TEMPLATE=stay.json
   API_KEY=Stay-ingAnonymous
3. Kjør `npm install` og `npm start` i crudops-mappen.
4. Kjør `npm install` og `npm run dev` i denne mappen.

## Ansvarsområder
- Sander Bendal:  hotelliste (index), registreringsside og innloggingssiden.
